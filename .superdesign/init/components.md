# Shared UI Components

No shared visual primitives exist yet. This is intentional: the Angular 17 rebuild is at the technical-foundation stage and the brief prohibits implementing product cards, buttons, inputs, dialogs, drawers, carousels, or other designed storefront components before Superdesign approval.

The temporary `FoundationPlaceholderPageComponent` is page-specific approval-gate evidence and is therefore not catalogued as a reusable UI primitive.
